# apps/mobile — App móvil de SoftArq

**Estado:** carpeta reservada. Aún no se ha inicializado el proyecto Expo ni hay dependencias instaladas.

**Tecnología prevista:** React Native con Expo.

## Responsabilidades

- Consulta y captura en campo (por definir el alcance exacto).
- Consume la API mediante los tipos de `@softarq/contracts`.
- No calcula importes oficiales, no decide permisos y no contiene reglas de negocio.
- Muestra de forma visible cuando los datos son DEMO.

## Antes de inicializar

Expo, Metro, Gradle y el SDK de Android escriben por defecto en el perfil de usuario de `C:` (por ejemplo `%USERPROFILE%\.expo`, `%USERPROFILE%\.gradle` y `%TEMP%`). Antes de instalar, definir sus rutas en `D:\Proyecto_SoftArq\_work` y anotarlo en `HANDOFF.md`.
